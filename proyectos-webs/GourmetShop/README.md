# GourmetShop

Tienda web de productos gourmet desarrollada como proyecto demostrativo.

## Incluye

- Catálogo de productos con filtros por categoría.
- Carrito de compras interactivo, con total y eliminación de artículos.
- Confirmación de compra simulada, sin procesamiento de pagos.
- Diseño adaptable para escritorio y dispositivos móviles.

Abrir `index.html` en un navegador. Las fotografías se cargan desde Unsplash, por lo que requieren conexión a Internet.

La imagen principal se incluye localmente en `assets/gourmetshop-hero.png`.
