# Evaluación Final - Programación Web I

Proyecto: página web para un estudio jurídico especializado.

## Archivos
- `index.html`: página completa con servicios, especialistas, áreas, tabla y formulario.
- `styles.css`: estilos con selectores de etiqueta, clase e identificador, modelo de cajas, CSS Grid, Flexbox y Media Queries.

## Ejecución
Abrir `index.html` directamente en un navegador. Las fotografías de la galería utilizan imágenes remotas de Unsplash, por lo que se requiere conexión a Internet para visualizarlas.

## Requerimientos cubiertos
1. Etiquetas y propiedades del formulario.
2. Formulario con nombre, correo, teléfono, país, mensaje y botón Enviar.
3. CSS para el formulario con selectores de etiqueta, clase e identificador.
4. Encabezados, galería y modelo de cajas.
5. Diseño de cuadrícula para servicios, especialistas, áreas y formulario.
6. Diseño responsivo con Flexbox y Media Queries.

El formulario incluye validación HTML5 mediante `required`, `type="email"` y `pattern`, y una demostración de envío con JavaScript.
